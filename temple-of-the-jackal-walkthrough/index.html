How this guide was verified

Verified boards and strategy, not invented button strings

The source video proves the board states below, while the recovered project proves each chamber's Par setting. Where the sampled footage cannot establish every individual left/right press, this guide does not pretend that it can. Follow the verified order of objectives, wait for every fall to settle, and compare the relationships between colors and obstacles rather than copying an unproven input string.

01

Chamber solution

Level 1

Par 3

Goal

Remove the red group and the three blue orbs from the open chamber.

Key idea

Use this room to learn that every quarter-turn changes gravity for every loose orb at once.

Step by step

  1. 1

    Read the red cluster as one stable mass and watch the separated blue orb above it.

  2. 2

    Rotate so the loose blue orb falls toward the two blue orbs on the right.

  3. 3

    Let the color groups resolve, then use the remaining turn to finish the room.

Normal clear

Keep matching colors on the same landing edge; there are no stones to trap a bad route.

Optimal / Par

The recovered level file sets the target at Par 3.

Common mistake

Turning again before the previous fall has settled can make the simple opening look harder than it is.

Walkthrough FAQ

01How many puzzle levels are in Temple of the Jackal?+

The main puzzle route contains 18 chambers. This walkthrough keeps all 18 solutions on one page so you can jump directly to the room that stopped your run.

02What do the left and right buttons do?+

Each button rotates the whole chamber by ninety degrees. Gravity then carries every loose orb and movable obstacle toward the new bottom edge.

03Do I have to beat Par to continue?+

No. Par is an efficiency target, not a gate. Clear every colored piece to finish a room; you can return later and reduce the number of turns.

04Is there a seven-move solution for Level 12?+

Yes. A seven-move clear is documented for Level 12 even though the recovered level file displays a more forgiving Par 11 target.

05Can Level 18 be cleared in ten moves?+

Yes. A ten-move optimized clear is documented for the final chamber; the recovered level file displays Par 12.

06Does the browser version save completed rooms?+

The game relies on browser-managed storage. Use the same browser profile, avoid private mode, and do not clear site data if you want to retain game progress.

07Can I play on Android or iPhone?+

The game can load in a modern mobile browser, but a landscape tablet or desktop is easier for reading the square board. Use fullscreen, wait for each fall to settle, and tap Retry below the player if the embedded build fails to load.

08Where do the walkthrough images come from?+

Every level image is a checkpoint captured from the linked Temple of the Jackal solution video. The Par values were checked against the recovered Godot level files.
